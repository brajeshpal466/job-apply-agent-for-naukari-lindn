## 4. Strict Technology Matching & Exclusion Rules

### ✅ Allowed Target Roles:
* `React Developer`
* `Frontend Developer`
* `Senior React Developer`
* `Senior Software Engineer` (React / TypeScript / JavaScript / Node / .NET focus)
* `Node.js React Full Stack Developer`
* `.NET React Developer`

### 🚫 STRICT EXCLUSIONS (Do NOT Apply):
* **NO JAVA ROLES**: Strictly reject and skip any job requiring `Java`, `J2EE`, `Spring`, `Spring Boot`, or `Java Full Stack`, even if React is mentioned as an auxiliary skill.
* **Skip Non-Aligned Roles**: Skip pure backend Python without React, pure Salesforce, QA / Manual Testing, or mobile-only Flutter/Android positions.

### ⏱️ Freshness Filter:
* **0–7 Days Only**: Strictly apply to jobs posted within **1 week or sooner (past 24h to past 7 days)**. Discard any posting older than 7 days.
